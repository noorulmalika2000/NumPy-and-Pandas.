# DS Assignment 1 – NumPy and Pandas
## 📌 Project Overview
This project is part of the Data Analytics (DA) – Module 2 assignment.
The objective of this assignment is to understand and perform basic data analysis using Python libraries such as NumPy and Pandas.
The assignment covers NumPy array operations, Pandas Series, and DataFrame creation, exploration, filtering, and manipulation.
## 🎯 Objectives
- Understand NumPy arrays and their properties.
- Perform numerical calculations using NumPy.
- Practice array indexing and slicing.
- Create and manipulate Pandas Series.
- Create and explore Pandas DataFrames.
- Perform filtering, grouping, and aggregation operations.
- Update, add, and delete DataFrame rows and columns.
## 🛠️ Technologies Used- Python
- NumPy
- Pandas
- Google Colab / Jupyter Notebook
## 📚 Assignment Tasks
### Part 1: NumPy Operations
- Created a 1D NumPy array for Week 1 temperature data.
- Inspected array shape, data type, and size.
- Converted Celsius temperatures into Fahrenheit.
- Calculated maximum, minimum, and mean temperatures.
- Performed array indexing and slicing.
- Created a 2D array containing two weeks of temperature data.
- Extracted weekly and weekend temperatures.

### Part 2: Pandas Series
- Created a Pandas Series named `marks`.
- Used integer indexing, `loc`, and `iloc`.
- Applied Boolean masking to filter marks greater than 90.
- Updated the first rank student's marks.
- Removed the last rank entry.
- Calculated CGPA by dividing marks by 10.

### Part 3: Pandas DataFrame
- Created a DataFrame named `transactions`.
- Explored data using `head()`, `tail()`, `shape`, `columns`, and `info()`.
- Selected specific columns using indexing.
- Filtered transactions based on region and amount.
- Used `value_counts()` and `unique()`.
- Grouped transactions by region and calculated mean amounts.
- Updated transaction amounts.
- Added a Discount column.
- Removed a transaction row and deleted the Discount column.
